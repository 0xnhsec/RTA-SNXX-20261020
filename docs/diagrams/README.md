# Diagram Mermaid

File di folder ini adalah sumber Mermaid mentah yang dipakai oleh dokumen workflow dan arsitektur.

| File | Isi |
|---|---|
| `01-adoption-workflow.mmd` | Alur adopsi dari inventaris sampai publikasi dan rollback |
| `02-verification-workflow.mmd` | Urutan verifikasi, evidence, dan cabang perbaikan |
| `03-runtime-load-flow.mmd` | Alur pemuatan modul MIT dan paket GPL saat runtime |

GitHub merender blok Mermaid yang disematkan di [`../02-WORKFLOW.md`](../02-WORKFLOW.md). File `.mmd` dapat dirender dengan Mermaid CLI atau editor yang mendukung Mermaid.
