# Mermaid diagrams

The files in this folder are the raw Mermaid sources used by the workflow and architecture documents.

| File | Contents |
|---|---|
| `01-adoption-workflow.mmd` | Adoption flow from inventory to publication and rollback |
| `02-verification-workflow.mmd` | Verification order, evidence, and remediation branch |
| `03-runtime-load-flow.mmd` | Runtime loading flow for MIT modules and the GPL package |

GitHub renders the Mermaid blocks embedded in [`../02-WORKFLOW.md`](../02-WORKFLOW.md). The `.mmd` files can be rendered with the Mermaid CLI or any Mermaid-capable editor.
